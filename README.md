# れいpay

友達同士で使う、架空の通貨「れい」の決済アプリです。本物のお金とは交換できません。

- はじめに招待コードを入れると **2000れい** もらえる（招待コードは1人1回だけ）
- ログインなし。このブラウザのクッキーで本人を見分ける
- クッキーが消えても **Face ID（パスキー）** で元に戻せる
- **バーコード決済**: 「支払う」でバーコード/QRを見せ、相手が読み取って金額を入れる
- **QR決済**: 「受け取る」のQRを相手が読み取り、相手が金額を入れて支払う
- 一覧から相手を選んで「送る」こともできる
- 残高を増やせるのは管理者の「配る」だけ

## しくみ

| 役割                       | 使っているもの                     |
| -------------------------- | ---------------------------------- |
| ソースコードの置き場       | GitHub                             |
| 公開とサーバーの処理       | Cloudflare Workers（無料プラン）   |
| ユーザー・残高・履歴の保存 | Cloudflare D1（無料のデータベース） |

GitHub Pages は画面のファイルを置くだけの場所で、残高や送金を記録するサーバーを動かせないため、
公開には Cloudflare を使います。GitHub とつないでおけば、GitHub を更新するたびに自動で公開し直されます。

送金や残高のチェックはすべてサーバー側で行うので、ソースコードが見えていても、
画面をいじって残高を増やすことはできません。

## 公開までの手順

### 1. GitHub にアップロードする

1. GitHub で新しいリポジトリ `reipay` を作る（Public でOK）
2. このフォルダの中身をすべてアップロードする

### 2. データベースを作る

1. [Cloudflare](https://dash.cloudflare.com/) に無料登録してログインする
2. [D1 SQL database](https://dash.cloudflare.com/?to=/:account/workers/d1) を開き、`reipay-db` という名前でデータベースを作る
3. 作ったデータベースの **Database ID** をコピーする

データベースの中の表（ユーザー・残高・履歴など）は、アプリが最初に開かれたときに自動で作られます。

### 3. 設定ファイルを書き換える

GitHub 上で `wrangler.jsonc` を開き、「★」の `database_id` を手順2でコピーした ID に書き換えて保存（Commit）する。

### 4. Cloudflare Workers で公開する

1. **Workers & Pages** → **作成** → **GitHub リポジトリをインポート** を選ぶ
2. GitHub と連携し、`reipay` リポジトリを選ぶ
3. Worker の名前は `reipay` にする（`wrangler.jsonc` の `name` と同じ）
4. デプロイコマンドは `npx wrangler deploy` のままで公開する

### 5. 管理者コードを登録する

Worker の **設定** → **変数とシークレット** で、次の値を **シークレット** として追加する。

| 名前         | 中身                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| `ADMIN_CODE` | 管理者になるための合言葉（20文字以上のランダムな文字列。誰にも教えない） |

### 6. 使い始める

1. 公開された URL（`https://reipay.<アカウント名>.workers.dev`）を開く
2. 招待コードの欄に `ADMIN_CODE` を入れて始める → 管理者になる
3. ホームの「Face ID を登録する」を押しておく
4. 「管理者メニュー」で招待コードを作り、友達1人に1つずつ渡す

iPhone では Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。
ホーム画面のアプリと Safari は記録が別々なので、ホーム画面に追加したあとは「Face ID で復元」で同じデータを開けます。

## パソコンで動かす（任意）

Node.js が入ったパソコンで、次のように動かせます。

```sh
npm install
cp .dev.vars.example .dev.vars   # 中身を書き換える
npm run db:migrate:local
npm run dev
```

## 安全のための仕組み

- 招待コードは1回しか使えないので、クッキーを消して作り直しても2000れいは増やせない
- クッキーにはランダムなトークンだけを入れ、データベースにはそのハッシュだけを保存
- Face ID の秘密鍵は端末（iCloud キーチェーンなど）から出ず、サーバーは公開鍵で本人かどうかを確かめる
- 支払いコードは5分で期限切れになり、1回しか使えない。新しいコードを出すと前のコードは使えなくなる
- 支払いコードにはチェック用の数字が入っていて、読み間違いや打ち間違いをはじく
- 残高はデータベースの制約でマイナスにならず、送金は「記録・引き落とし・入金」を1つの処理としてまとめて実行
- 画面は自分のファイル以外のスクリプト・スタイルを読み込めない設定（CSP）
